## E2E 覆盖

- 注册、重复账号、错误密码、资料修改、账号搜索、匿名拒绝、身份头不能伪造操作人、未知业务字段拒绝。
- 好友申请重复提交、接受、拒绝、取消、越权拒绝、列表分页、备注、删除与恢复、拉黑及解除。
- 私聊双方唯一会话、文字发送、离线补拉、已读不回退、已读越界拒绝、外部用户读取/发送拒绝。
- 发送键重复重放、首次并发发送、已有发送并发重放、不同载荷冲突、超长内容拒绝。
- JSON 长连接认证、请求号心跳、文字在线投递、撤回在线事件、无效凭据拒绝，旧 HTTP 和长连接路径不可访问。
- 群与会话 ID 分离、建群、审批入群、拒绝、邀请去重、成员列表、群主改名、普通成员越权拒绝。
- 成员移除、退出、群主退出限制、解散、成员状态离线同步、撤回历史投影、事件补拉与确认不回退。
- 开放群立即加入、新成员加入前历史隔离、加入后消息可见。
- 登录替换、刷新撤销旧 Token、并发刷新只允许一次成功、修改密码撤销会话、新密码登录、注销、注销连接停止接收。
- RabbitMQ 停止期间发送成功且消息可补拉；启动后恢复在线投递，并继续处理后续消息。
